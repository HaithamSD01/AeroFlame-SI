# AeroFlame edge node - wiring & bill of materials

| Part | Pin on part | ESP32 pin | Note |
|---|---|---|---|
| IR flame sensor module | VCC / GND / DO | 3V3 / GND / GPIO 5 | Most modules pull DO LOW when they see flame |
| MQ-2 smoke/gas sensor | VCC / GND / AO | 5V (VIN) / GND / GPIO 34 via divider | AO can reach 5 V: use 10 kΩ + 20 kΩ divider -> max 3.3 V. Warm up 1-2 min |
| BME280 (temp, pressure, humidity) | VIN / GND / SDA / SCL | 3V3 / GND / GPIO 21 / GPIO 22 | I2C address 0x76 or 0x77 |
| Active buzzer | + / - | GPIO 13 / GND | Local alarm, works without the dashboard |

Bill of materials (~ low cost): ESP32 DevKit, IR flame sensor, MQ-2, BME280, active buzzer,
2 resistors (10 kΩ, 20 kΩ), breadboard + jumpers, USB cable.

## Run it
1. Arduino IDE: install the ESP32 board package and the "Adafruit BME280" library.
2. Open `aeroflame_node/aeroflame_node.ino`, select your ESP32 board and COM port, Upload.
3. Serial Monitor at 115200 baud should show one JSON line per second, e.g.
   `{"node":"AF-01","uptime_s":12,"flame_detected":false,"temperature_c":23.41,"pressure_hpa":1009.82,"humidity_pct":41.20,"smoke_raw":512}`
4. Close the Serial Monitor (it locks the port), start the dashboard (run.bat), open
   "Live Habitat Monitor", choose "ESP32 over USB" and pick the COM port.

## No hardware? (virtual fallback)
- In the dashboard choose "Simulation": the same JSON is generated by `simulation/aeroflame_model.py`.
- Or build the circuit in Wokwi (wokwi.com, ESP32 project) or Tinkercad; Wokwi includes flame and
  gas-sensor parts. Paste the .ino code; check that its BME280 part is available or use the simulation.

## Why these sensors (validity)
- Microgravity removes buoyancy, so smoke does not rise to a ceiling; NASA places ISS smoke detectors
  in cabin air return vents. Put the node in the ventilation return path.
- NASA's SAME results showed a single light-scattering detector missed Kapton and Teflon smoke in many
  tests, and dust causes nuisance alarms. AeroFlame fuses three independent signals (IR flame, smoke,
  heat/pressure trend) instead of trusting one.
